# Addíció
- Br$_{2}$-addíció / halogén addíció
	- Katalizátor nem kell
- H$_{2}$-addíció / telítés
	- Olaj keményítés → telített zsír (margarin)
	- CH$_{2}$ = CH - CH$_{3}$ + H$_{2}$ $\xrightarrow{katalizátor(Pt), T\uparrow}$ CH$_{3}$ - CH$_{2}$ - CH$_{3}$     prop-1-én
	- Növényi olajok $\xrightarrow{H_{2}, addíció}$ margarin     zsírkeményítés
- HCl addíció / sav addíció
	- Katalizátor, T$\uparrow$
	- CH$_{2}$ = CH$_{2}$ + HCl → CH$_{3}$ - CH$_{2}$Cl ![[2. Drawing 2026-01-05 10.33.34.excalidraw]]
	- Markovnyikov-szabály
		- A hidrogén mindig oda megy, ahol eleve több hidrogén volt

# Polimerizáció
- Polimer: Óriási molekula, ami **sok** azonos alkotórész összekapcsolódásával jön létre
	- h CH$_{2}$ = CH$_{2}$ → -(-CH$_2$-)-$_{n}$
	- $CH_{2} = CH_{2} + CH_{2} = CH_{2} + CH_{2} = CH_{2} \rightarrow - CH_{2}-CH_{2}- + -CH_{2}-CH_{2}- + -CH_{2}-CH_{2}-$ etén, etilén
	- → $-CH_{2}-CH_{2}-CH_{2}-CH_{2}-CH_{2}-CH_{2}-$ Polietilén
