# Metán CH$_{4}$
- kicsi aktiválási energia
- a metán a levegőben robbanóelegyet alkot
	- bányákban súlytóléghatás
- földgáz
	- kőzetek pórusaiban található
	- városi gáz metánt tartalmaz
	- kellemetlen szag (kén tartalmú vegyülettel szagosítják)
#### Molekulaszerkezet
- tetraéderes
	- α = 109,5°
		![[1. Drawing 2025-10-13 10.34.05.excalidraw]]
	- ΔEN = 0,4 => gyengén poláris kovalens kötés
		- molekula apoláris
#### Fizikai tulajdonság
- gáz (szobahőmérséklet)
- színtelen
- szagtalan 
	- szagosítják → ‘S’
- olvadáspont, fagyáspont → nagyon alacsony
	- olvadáspont: -180°C
	- forráspont: -160°C
- molekularács → diszperziós kötés (gyenge!)
	- M$_{CH_4}$ = 12 + 4 * 1 = 16$\frac{g}{mol}$
- oldhatóság
	- vízben nem oldódik
	- apoláris oldószerekben oldódik
- $\rho$ = $\frac{m}{V}$ → $\frac{M}{V_{mol}}$     $\overline{M}_{levegő}$ = 29$\frac{g}{mol}$ > M$_{CH_4}$ = 16$\frac{g}{mol}$ => $\rho_{lev}$ >$\rho_{metán}$

#### Kémiai tulajdonság
- éghető
	- CH$_{4}$ + 2O$_{2}$ → CO$_{2}$ + 2H$_{2}$O      $\Delta_{r}$H < 0
		 tökéletes égés                    ~ -891$\frac{kj}{mol}$ Exoterm
- szubsztitúció (helyettesítés)
	- olyan reakció amelyben a kiindulási vegyület egy atomját vagy atomcsoportját más atomra vagy atomcsoportra cserélünk
	- metán klórozása
		- CH$_{4}$ + Cl$_{2}$ → robbanóelegy

		- CH$_{4}$ + Cl$_{2}$ → CH$_{3}$Cl + HCl

		- CH$_{3}$Cl + Cl$_{2}$ → CH$_{2}$Cl$_{2}$ + HCl

		- CH$_{2}$Cl$_{2}$ → CHCl$_{3}$ + HCl
				  triklórmetán
		- CHCl$_{3}$ → CCl$_{4}$ + HCl

# Alkánok
- **Homológ sor**
	- Tagjai közötti különbség ($-CH_{2}-$)
	- 1. Metán
	- 2. Etán $C_{2}H_{6}$
	- 3. Propán $C_{3}H_{8}$
	- 4. Bután $C_{4}H_{10}$        CH$_{3}$-CH$_{2}$-CH$_{2}$CH$_{3}$ = CH$_{3}$($-CH_{2}-$)CH$_{3}$
	- 5. Pentán $C_{5}H_{12}$
	- 6. Hexán $C_{6}H_{14}$
	- 7. Heptán $C_{7}H_{12}$
	- 8. Oktán $C_{8}H_{18}$
	- 9. Nonán $C_{9}H_{20}$
	- 10. Dekán $C_{10}H_{22}$
- **Nevezéktan**
	1. -án végződés
	2. Leghosszabb szénlánc elnevezése
	3. Szénlánc számozása úgy, hogy az elágazás a <u>legkisebb</u> sorszámot kapja
		- A <u>számot</u> az alap szénhidrogén neve <u>előtt</u> jelezzük
		- Számok és név között kötőjel
	4. Több azonos elágazás esetén a <u>di</u> vagy <u>tri</u> szócskát használunk
- **Fizikai tulajdonságok**
	- Molekulaszerkezet: tetraéderes kötések → apoláris molekulák → diszperziós kötés
		- Ereje nő, ha a molekula mérete/tömege nő
	- Halmazállapot (T = 20°C, p = 10$^5$Pa)
		- C$_{1}$ - C$_{4}$: gáz
		- C$_{5}$ - C$_{16}$: folyadék
		- C$_{n}$ > C$_{16}$: szilárd
	- Jellegzetes szag
		- benzinszag
- **Kémiai tulajdonságok** (T$\uparrow$)
	- Tökéletes égés
		- C$_{6}$H$_{14}$ + $\frac{19}{2}$O$_{2}$ → 6CO$_{2}$ + 7H$_{2}$O (12’O’ + 7’O’ $\Rightarrow$ 19’O’)
	- Helyettesítés / szubsztitúció
		- $C_2H_6 + Cl_2 \xrightarrow{T\uparrow _{V} U.V.} C_2H_5Cl + HCl$
							- klór-etán
			- halogénezett-szénhidrogének
				- teflon
				- freon
	- Hőbontás-krakkolás
		- Magas T, nincs O$_{2}$, magas p
