# Sejtek
- **Sejt:** élő anyag legkisebb önálló egysége, ami még önálló anyagcserét mutat és szaporodásra is képes
- **Prokarióta sejtek:** sejtmag nélküli sejtek (baktériumok)
- **Eukarióta sejtek:** sejtmagvas sejtek (növények, állatok, gombák)
- **Sejtalkotó:** membránnal körülvett test

# Sejthártya / sejtmembrán
- Minden eukarióta sejtben
- Külső határoló membrán
- Feladatai
	- Határolás
	- Összekötés
	- Anyagforgalom
	- Jelölés
	- Jelfogás
- Felépítése: kettős hártya
	- Kettős foszfolipid réteg (sejthártya alakja)
	- Koleszterin (folyékonyság szabájozása)
	- Fehérje (sejthártya fajlagossága)
		- Csatornafehérje
		- Szállítófehérje
		- Receptorfehérje = jelfogó
		- Jelölő fehérje (sejtek beazonosítása)
		- Enzimfehérjék

# Sejtplazma / Citoplazma
- Minden eukarióta sejtben
- Sejthártya és sejtalkotók közötti tér
- Vizes, kocsonyás “töltőalak", reakciók színtere
- Merevítőanyagok → fehérjék
	- Kusza hálózat → “sejtváz”
		- Fibriláris (szál alakú) fehérjékből áll
	- Merevít, alakot tart
	- Sejtalkotók mozgását segíti
		- “Sínek”
	- Enzimek kapcsolódnak hozzá

# Sejtmag /nukleus
- minden eukarióta sejben
	- 1db (vörövérsejt (0), haráncsíkoltizomsejt (sok))
	- Középen
- Két membrán határolja
	- Kettős sejthártya
- Pórusok → mRNS kijutása
- Alapállománya → nukleinsavak
- Feladat: genetikai állomány védelme
- Sejtmagvacska → RNS tartalmú

# Riboszóma
- Minden eukarióta sejtben
- Sejtplazmában szabadon (v. Der-hez kötötten)
- Nem határolja membrán
- Két alegységből áll
- rRNS + hozzá kapcsolódó tRNS, mRNS, aminosavak
- Feladata: fehérjeszintézis helszíne
- Kötött riboszóma: Endoplazmatikus retikulum felszínén
	- Endoplazmatikus retikulum → “durva felszínű”
