# Sejtek
- **Sejt:** élő anyag legkisebb önálló egysége, ami még önálló anyagcserét mutat és szaporodásra is képes
- **Prokarióta sejtek:** sejtmag nélküli sejtek (baktériumok)
- **Eukarióta sejtek:** sejtmagvas sejtek (növények, állatok, gombák)
- **Sejtalkotó:** membránnal körülvett test

# Sejthártya / sejtmembrán
- Minden eukarióta sejtben
- Külső határoló membrán
- Feladatai
	- Határolás
	- Összekötés
	- Anyagforgalom
	- Jelölés
	- Jelfogás
- Felépítése: kettős hártya
	- Kettős foszfolipid réteg (sejthártya alakja)
	- Koleszterin (folyékonyság szabájozása)
	- Fehérje (sejthártya fajlagossága)
		- Csatornafehérje
		- Szállítófehérje
		- Receptorfehérje = jelfogó
		- Jelölő fehérje (sejtek beazonosítása)
		- Enzimfehérjék

# Sejtplazma / Citoplazma
- Minden eukarióta sejtben
- Sejthártya és sejtalkotók közötti tér
- Vizes, kocsonyás “töltőalak", reakciók színtere
- Merevítőanyagok → fehérjék
	- Kusza hálózat → “sejtváz”
		- Fibriláris (szál alakú) fehérjékből áll
	- Merevít, alakot tart
	- Sejtalkotók mozgását segíti
		- “Sínek”
	- Enzimek kapcsolódnak hozzá

# Sejtmag /nukleus
- minden eukarióta sejben
	- 1db (vörövérsejt (0), haráncsíkoltizomsejt (sok))
	- Középen
- Két membrán határolja
	- Kettős sejthártya
- Pórusok → mRNS kijutása
- Alapállománya → nukleinsavak
- Feladat: genetikai állomány védelme
- Sejtmagvacska → RNS tartalmú

# Riboszóma
- Minden eukarióta sejtben
- Sejtplazmában szabadon (v. Der-hez kötötten)
- Nem határolja membrán
- Két alegységből áll
- rRNS + hozzá kapcsolódó tRNS, mRNS, aminosavak
- Feladata: fehérjeszintézis helszíne
- Kötött riboszóma: Endoplazmatikus retikulum felszínén
	- Endoplazmatikus retikulum → “durva felszínű”

# Endoplazmatikus hálózat / retikulum
- Der
	- felszínén riboszómák → durva felszínű
- Ser
	- nincsenek a felszínén riboszómák → sima felszínű

# Lizoszóma (bontótest)
- Minden állati sejtben
- Feladata: *sejten belüli lebontás, emésztés*
	- Sejten belüli elöregedett sejtalkotókat (*Autofágia*)
	- Sejtbe került idegen anyagokat (Heterofágia)
		- pl. baktérium, vírus

# Mitokondrium
- Minden eukarióta sejtben
- ATP szintézis helye
	- Adenozin-trifoszfát
	- Szervezet lebontja → belőle felszabaduló energiát használja fel
- Szerkezet
	- Kettős membrán
		- Külső membrán
		- Belső membrán
			- Sokkal nagyobb, mint a külső
			- Betüremkedések
			- Terminális oxidáció
	- Alapállomány
		- Riboszómák
		- Mitokondriális DNS
		- Szemcsék
			- Bakteriális sejtekre hasonlít
		- Citromsav ciklus
	- Két membrán közötti tér
- Evolúciós eredete
	- Endoszimbionta elmélet
		- Egy egysejtű bekebelezte a mitokondriumot
		- Bizonyíték
			- Függetlenül tud a sejttől osztódni
			- Más fajta határló membrán

# Sejtfal
- Alakot ad és védi a sejtet
    - Nem határolja el a környezettől
        - Rengeteg pórus
- Növényi → Cellulóz
- Gombák → Kitin

# Zöld színtest (kloroplasztisz)
- Kizárólag növényi eukarióta sejtekben
- Felépítése
	- Külső membrán
	- Belső membrán
	- Két membrán közötti tér
	- Alapállomány (riboszóma, gyűrűs DNS, enzimek)
- Benne játszódik le a fotoszintézis
	- Gránumban van a fényszakasz, színanyagok
	- Alapállományban sötétszakasz
- Eredete: endoszimbionta elmélet
